# Code review, 2026-10-29: the whole tree

Scope: every Lua file of the six mods (DanTraits 110 files, Dan's Vanilla Fixes 9, Base Unloader 7, Map Legend 3, Vitality Cartridges 18, Vitality Challenges 10), the item scripts, the EN translations, the tooling (`deploy.py`, `tests/run_tests.py`, `lint_kahlua.py`, `check_api.py`, `harness.lua`) and the uncommitted work since 0990978 (Newbie Gains, the Daily Medication window, the Heart cold rule, the TIYL game-mode patch, The Last Broadcast phase 2). Six reviewers read the tree by area; every finding below marked **fixed** or **confirmed** was traced in the working tree by hand before anything was changed, most against the installed 42.21 game Lua and jar.

Baseline: `python tests/run_tests.py` 98/98 (lint 165 files clean, one 52/60-upvalue warning in `updateDiabetesMinute`; `check_api.py` 0 problems). After the fixes: 98/98, lint now 183 files (the cartridges included), 0 errors.

## Verdict

The plumbing is in good shape and the reviewers said so independently: every game call sits in `pcall` or `DanTraits_Guard`, wraps are idempotent by tag and `new()` is refused at the one choke point, the clock registrations document their order, and the tests mirror the behaviour closely enough that several suspected bugs turned out to be pinned and intended. No Kahlua-illegal syntax anywhere; the cross-checks (every `DanTraits_Wrap` target exists in the game's Lua, every translation key resolves, every `Base.*` item id exists, every receiver `check_api.py` knows about is clean) all pass.

The real defects were of three kinds. One systemic: the five `Events.AddXP` handlers each adjusted the *original* gain and the shares summed, so stacked penalties could go net negative (A1.1). A handful of plain logic slips in newer code: a sort in place with labels read by the old index (coolers), a container key that could not tell stacked crates apart (Base Unloader), the cold's share added after the drain with the rate on it (Heart), the Neat Rocco guard applied to one of two loops (fitness window). And a cluster of "the local player is slot 0" assumptions in event handlers, which the clocks stopped making on 2026-10-16 but the events never did (split-screen only).

Multiplayer is as the mod says: singleplayer. Section B collects what the reviewers found for `plans/multiplayer.md`; nothing there is new in kind.

## A. Bugs

### A1. Fixed in this pass (all tested, suite 98/98, deployed, unplayed)

1. **Experience shares summed; a penalty could exceed the gain.** `DanTraits_Fitness.lua`, `DanTraits_Strain.lua`, `DanTraits_Age.lua`, `DanTraits_AgeTraits.lua`, `DanTraits_ADHD.lua` each computed `amount * (k - 1)` and sent it through `DanTraits_AgeXpAdjust`, which hides it from the others. A 50s character (x0.8) at Breaking Point (x0.15) gaining 10 Strength: Age takes 2, Burnout takes 8.5, net -0.5; with Overtrained and a Sore rep (x0.42) every rep drained the level already earned, and `StrainXpFloor`'s promise was false whenever another handler also cut. **Fix:** `DanTraits_XpFactor(player, perk, amount, k)` in core keeps one running product per event (core's own `AddXP` listener, registered first, opens the record; the quiet adjust's own event is ignored; a loud addition inside the event, Vitality's Thriving, keeps the outer record one deep), and each handler multiplies into it and applies only the difference. `tests/test_xpstack.lua` now pins the products (1.68, 3.15, 1.12) and a two-cut case (x0.8 then x0.5 on 10 leaves 4, the sums left 3). **Confirmed, fixed.**
2. **Base Unloader: same-kind containers on one square shared a key.** `BU.key` was `x,y,z:kind:index` with `index` the container's position *within its object*, so three stacked crates were all `x,y,z:crate:0`: `byKey` kept the last, `S.resolve` returned the first, and names, rules, tags, Off limits and deliveries applied to all three. **Fix:** `S.ordinalOf(sq, obj, kind, index)` counts the same-kind objects before this one on the square; the key carries `#n` for n > 0 (old keys parse as the first), `S.resolve` walks to the n-th. Test added. **Confirmed, fixed.**
3. **Coolers: pack names swapped.** `C.drainPool` sorted `states` in place; the label loop then read `states[i]` as pack i. With packs at 6, 6, 3 h and ten hours of warmth the spent pack read "Frozen". Mod data was right. **Fix:** the drain sorts a copy. Test added. **Confirmed, fixed.**
4. **Heart: the cold could still build strain at rest.** The 2026-10-28 rule added `chill * strainRate` after the rest drain; chill reaches 0.02 and the rate 1.95 for a Smoker on caffeine (x3 after adrenaline), so 0.039 > the 0.03 light-activity drain and strain climbed walking in a blizzard. **Fix:** `strain - max(0, drain - chill * rate)`. **Confirmed, fixed.**
5. **Fitness window: the Neat Rocco guard was missing from the anchor loop.** `placeButtons` got the `type(b) == "table"` check on 10-28; the `initialise` wrap's `setAnchorBottom` loop did not, so under Neat Rocco the pcall died after `addChild` and the window never grew. **Fix:** same guard, `closeBtn` included. **Confirmed, fixed.**
6. **Split-screen: seven event handlers took "local" to mean slot 0.** Blood's refund (`onBloodGetDamage`), Concussion (`DanTraits_HeadHit`, `onConcussionDamage`, `onConcussionSwing`), Brittle (`DanTraits_BrittleHit`, the impact hook), Heart's weak swing, Tinnitus's shot, Anger's `isLocal`, WoundCare's swing, Util's `DanTraits_OtherHit` / `DanTraits_MeasureHit`, A-Life's `wrapHit`. Player 2's bleed was drained by our model *and* vanilla's health loss stayed; their head hits never concussed. **Fix:** `DanTraits_IsLocalPlayer(character)` in Util (any slot 0-3), used at every site; WoundCare's `moved` flag is per character (`d.wcMovedNow`). Test added in `test_blood.lua`. **Confirmed, fixed.**
7. **Newbie Gains: the baseline was written by whichever caller ran first**, the XP path included (which fires after the game added, so a level crossed there moved the start up one), and a failed `getPerkLevel` wrote 0 for good. **Fix:** only `newbieMinute` writes it, only from a successful read; `newbieLeft` is read-only and 0 until then. **Confirmed, fixed.**
8. **Daily Medication window: a stale instance after a new character.** `DanTraitsMedWindow.instances` outlived the world; the first click of the pill button closed a window that was gone. **Fix:** cleared on `OnCreatePlayer`. **Confirmed, fixed.**
9. **The Last Broadcast: the grace evening cost listeners and said "Nobody heard you".** `MISSED_START = -1` only spared the failure count. **Fix:** `B.settle` returns "grace" with no loss and no halo while `missedInRow < 0`. Also: the 96.4 "Vitality Challenges" channel was registered into every save that loaded the mod with nothing airing on it (removed until a challenge uses it); `airText` nulls a vanilla script that started since the hour's silencing before each line. **Confirmed, fixed.**
10. **Vitality Cartridges: menu cues bypassed SOUND OFF** in Steady, Still Water, Spiffo Walk and First Aid Quiz (`self.sequencer:effect` straight; Spiffo Pup used `cue`). **Fix:** every cue through `cue()`. **Confirmed, fixed.**
11. **Map Legend:** `copyToProfile` wrote the file twice (itself and through `ML.changed(nil)`); `readProfile` / `writeProfile` closed the handle inside the pcall, so a throw leaked it. **Fixed.**
12. **SpiffBoy mood wrap** returned nothing on the scaled path (the `DanTraits_Wrap` contract is to return the original's result). **Fixed.**
13. **Base Unloader, smaller:** the freezer stage ranked only exact `COLD_KINDS`, so a modded "minifridge" was kept out of dry goods but never picked for fresh food; `BU.suggest`'s probe had no weight, so a full container could be suggested; groups split clean from dirty laundry but not fresh from rotten food, so the label said "Fridge" for a group half of which went to the bin. All three **fixed**, with the stale `S.allItems` comment removed.
14. **Tooling:** `deploy.py --pull` used the mirroring sync, so a file in the repo but not yet deployed was deleted from the repo on pull (now add-and-update only); the mod flags were not exclusive (`--patch --challenges` silently took the last); `VitalityCartridges/` was in neither `lint_kahlua.py` nor `check_api.py` (added; 0 findings); `run_tests.py` guarded `node` but not `npm`. **Fixed.** (`lint_kahlua.py`, `check_api.py` and `run_tests.py` are skip-worktree in this checkout, so those edits stay local.)
15. **Comments that contradicted the code**, fixed in place: the driver-order table in `DanTraits.lua` (missing HotWaterBottle 20, Adrenaline 35, Brittle and Fitness 40, Headphones 41, Relaxant 60, SleepMenu 90, SensoryShutdown 40 and the hungerRise / panicRise pipelines); "Core's one OnCreatePlayer handler" (there are four, in a relied-on order); `DanTraits_ScaleActionTime` and Hemophobia's header both said `ISSplint.new` is wrapped (it is `getDuration`); Adrenaline's "rolls the heart again" (not while an attack is already pending); Heart's mod-data list (`hcEndFrame`); the Util index (`DanTraits_StormComing`, `DanTraits_IsLocalPlayer`); Concussion's `a or b and c` parenthesised; Home's dead `or nomad` clause removed; the Fitness sandbox tooltip says Newbie Gains is off with the system.

## D. Feature ideas

Sized as the backlog does (S an evening, M a few sessions, L a design doc first).

1. **"What's new" on first load after an update** (S). A version stamp in the world's mod data; when the mod's version is newer, one dialog with the Workshop changelog's headline lines for that version and a "don't show again". Most Workshop players never read a changelog, and the field guide was removed for being bloated; this is the two-paragraph version, once.
2. **A `vitality doctor` console command** (S). Prints which compatibility adapters found their mod (This Is Your Life, Project A-Life, Bandits, SpiffBoy, Neat Rocco, Take A Bath And Shower, Smarter Storage, Home Inventory Improved), which sandbox systems are off, the clock registrations and the last guard failures. Half of every bug report is finding out which of these is loaded.
3. **Base Unloader: stock thresholds and a shopping list** (M). The stock counts and "At base: N" already exist; a per-type "keep at least N" on the rule writes a red line in the base inventory window when the base is short, and a one-page list to take on a run. Pairs with the resume logic that already survives a trip.
4. **Base Unloader: the trip in reverse** (M). Load a vehicle from the base for an expedition by the same tags ("Camping", "Medical"), using the same route and carry rules. Everything but the direction is built.
5. **Frozen water bottles as cold packs** (S, Dan's Vanilla Fixes). A sealed water bottle frozen in a freezer behaves as a Coldpack in a cooler at half the hours; it is what people actually do, and the model is already there.
6. **Map Legend: an auto-legend** (S). Read the symbols and colours already drawn on the world map and offer "add the ones not in the legend" with blank names; the legend then starts from what the player has been doing instead of from nothing.
7. **A weekly Vitality note** (M). Once a game week, a Notes-tab page from the telemetry the mod already keeps: nights slept well, days on plan, meals by tier, burnout's high and low, what eased it most. The Notes tab exists; this is the first page that writes itself.
8. **Cartridge: "Night Watch"** (M). A Vitality Cartridge where a lantern must be kept lit through a night by tapping in rhythm with a slowing cue; a good run counts as the calm hour Burnout drains on, so a sleepless night has something to do. Still Water's bridge into Burnout is the template.
9. **Catchable illnesses** (L) and **Age v2** (L) stay the big items; both have designs in the backlog. Settle the one-fever-owner question first (wound infection holds and resets SICKNESS itself today), since the Heart, Strain and Adrenaline work of this month all read the fever.
